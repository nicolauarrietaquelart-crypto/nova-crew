NOVA CREW v14 — CLOUDFLARE

1) Sube NOVA_Crew_v14_Cloudflare.zip (SIN DESCOMPRIMIR) a tu repo GitHub nova-crew.
2) Crea .github/workflows/instalar-cloudflare.yml con el contenido del instalador proporcionado aparte.
3) GitHub -> Actions -> Instalar NOVA Crew v14 Cloudflare -> Run workflow.
4) Cloudflare -> Workers & Pages -> Create application -> GitHub -> elige repo nova-crew.
5) Worker name: nova-crew-demo; Deploy command: npx wrangler deploy.
6) Despliega. Cloudflare usará wrangler.jsonc y creará el almacén Durable Object automáticamente.

IMPORTANTE: NO selecciones Cloudflare Pages/solo estáticos: el QR necesita el Worker.

Demo: demo / crew2026 (trabajador); coord / coord2026 (coordinador).
Lee README.md para instrucciones detalladas y limitaciones.
