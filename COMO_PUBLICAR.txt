NOVA CREW V13 — NETLIFY (DEMO GRATIS)
===================================

1. Descomprime el ZIP.
2. Sube TODO el proyecto a un repositorio GitHub.
3. Netlify > Add new project > Import an existing project > GitHub.
4. Selecciona el repositorio y pulsa Deploy.
5. Publicar: public/ ; Functions: netlify/functions (incluidos en netlify.toml).
6. Abre la URL HTTPS que te dé Netlify DESDE DOS MOVILES.

TRABAJADOR: demo / crew2026
COORDINADOR: coord / coord2026

NEON DISTRICT: trabajador demo enseña su QR; coord lo escanea.
URBAN WAVE: coord enseña su QR como HAND; demo lo escanea como Crew Head.
ELECTRA: demo ficha directamente porque no hay coordinador.

El lector usa la cámara DENTRO de NOVA Crew, no abre una web externa.
El backend compartido necesita Netlify Functions y Blobs. Un HTML suelto no sirve.

LEER README.md para instrucciones, límites y pruebas.
